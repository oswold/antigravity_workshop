Use the SonarQube MCP tool to scan the project codebase, generate a detailed report of findings, and automatically fix issues classified as high severity vulnerabilities. Ensure that medium and low severity issues are reported but not auto‑fixed. Provide a summary of the fixes applied, including file names and changes made, and confirm that the updated code passes the SonarQube re‑scan. Test the code for it's working after making the change to ensure it's working fine.
